ZAKÁZKÁŘ – MOBILNÍ APLIKACE S NAŠIMI TIPY

Mobilní verze po otevření nabízí dvě části: Poptávky a Naše tipy.
Přihlášení nebo registrace je nutná pro komunitní feed. Každý přihlášený uživatel může zveřejnit tip, přidat fotografii, lajkovat a komentovat příspěvky ostatních.

NAHRÁNÍ NA GITHUB A RENDER
1. Rozbalte ZIP.
2. Nahrajte všechny soubory z rozbalené složky přímo do kořene repozitáře na GitHubu. Při výzvě potvrďte nahrazení stávajících souborů.
3. V Renderu zvolte službu Web Service. Root Directory ponechte prázdné.
4. Build Command: npm install
5. Start Command: npm start
6. V Renderu vyberte Manual Deploy → Deploy latest commit.
7. Po dokončení otevřete hlavní veřejnou adresu aplikace. Na stránce přepínejte mezi Poptávkami a Našimi tipy.

Soubory package.json, server.js, mobilni-zakazkar.html a zakazkar-vylepsena.html musí být vedle sebe přímo v kořeni repozitáře.

ÚČTY A UKLÁDÁNÍ
Každý uživatel si vytvoří účet s e-mailem a heslem o délce alespoň 10 znaků. Tipy, lajky a komentáře ukládá server. Bez trvalého úložiště Renderu mohou být data po restartu služby ztracena. Pro dlouhodobý provoz nastavte trvalý disk nebo databázi.
